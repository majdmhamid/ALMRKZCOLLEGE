## 2. شو انبنى (بلغة بسيطة)

موقع كامل بالعربي (`/ar/...`) والعبري (`/he/...`)، اتجاه RTL، سريع، وملائم للموبايل:

| الصفحة | الرابط (عربي) |
|---|---|
| الرئيسية | `/ar` |
| الدورات (3 مجموعات) | `/ar/courses` |
| صفحة مجموعة | `/ar/courses/welding` · `/ar/courses/hvac` · `/ar/courses/construction-safety` |
| صفحة دورة (11 دورة) | مثل `/ar/courses/welding/welding-electrode-co2` |
| عن الكلية (+ الطاقم + الشركاء) | `/ar/about` |
| الخريجون (16) | `/ar/graduates` |
| الصور والفيديو | `/ar/gallery` |
| أخبار (6 منشورات) | `/ar/news` |
| للشركات والمشغّلين | `/ar/employers` |
| اتصل بنا (خريطة + استمارة) | `/ar/contact` |
| إعلان الوصولية | `/ar/accessibility` |

موجود بكل الصفحات: زر واتساب عائم، استمارة "سجّل اهتمامك" (اسم + هاتف إلزامي، الإيميل اختياري)، أداة وصولية أولية، تبديل لغة يودّي لنفس الصفحة، SEO كامل (عنوان ووصف لكل صفحة، hreflang، sitemap، Schema).

**القواعد الثلاث (لا أسعار، لا ضمان تشغيل، صياغة المنح الثابتة) مطبّقة في كل النصوص.** التواريخ القديمة لا تُعرض؛ بدلها "الموعد القادم: تواصل معنا". مجموعة "إدارة وتسويق" غير معروضة.

## 3. كيف تشغّل الموقع محلياً

```bash
npm install
npm run dev
```
ثم افتح `http://localhost:3000/ar` (أو `/he`).

أوامر أخرى: `npm run build` (بناء كامل للتأكد إن كل شي سليم) · `npm run lint` · `npm run images` (إعادة ضغط الصور من `assets/`).

```
content/            ← كل المحتوى هنا (بدون لوحة تحكم بهذه المرحلة)
  courses.ts        11 دورة — اسم، وصف، مواضيع، شروط قبول، شهادة (عربي + عبري)
  groups.ts         المجموعات الثلاث
  people.ts         الطاقم (6) · الخريجون (16) · الشركاء (5)
  news.ts           الأخبار (6)
  media.ts          صور المعرض وفيديوهات يوتيوب
  i18n.ts           كل نصوص الواجهة والصفحات العامة بالعربي والعبري
  site.ts           اسم الكلية، الهواتف، العنوان، الروابط
src/app/[locale]/   الصفحات (Next.js App Router)
src/components/     الترويسة، التذييل، الاستمارة، الواتساب، المعرض، أداة الوصولية، القياس (Analytics)
src/app/actions/lead.ts        استقبال الاستمارة وإرسالها بالإيميل
scripts/optimize-images.mjs    يضغط الصور من assets/ إلى public/images/
public/images/      الصور الجاهزة للموقع (مضغوطة، 12 ميغا بدل 100)
assets/             الصور الأصلية (لا تُستخدم مباشرة في الموقع)
```

كل نص فيه نسختان `{ ar: "...", he: "..." }` — هذا الشكل مقصود ليصير "حقول مترجمة" في Payload CMS لاحقاً بدون تغيير الصفحات.

## 5. مفاتيح لازم تتعبّى قبل الإطلاق (ملف `.env.local` أو إعدادات Vercel)

انسخ `.env.example` إلى `.env.local` وعبّي:

| المفتاح | شو بيعمل | من وين |
|---|---|---|
| `RESEND_API_KEY` | إرسال الاستمارة بالإيميل | حساب مجاني على resend.com |
| `LEAD_TO_EMAIL` | الإيميل اللي توصله الطلبات | افتراضياً `almerkaz.collega@gmail.com` |
| `LEAD_FROM_EMAIL` | عنوان المرسل (دومين موثّق في Resend) | بعد ربط الدومين |
| `NEXT_PUBLIC_GA_ID` | Google Analytics 4 | analytics.google.com |
| `NEXT_PUBLIC_META_PIXEL_ID` | Meta Pixel (فيسبوك/إنستغرام) | Facebook Business |
| `NEXT_PUBLIC_SITE_URL` | الرابط النهائي | `https://www.almrkz.net` |

بدون `RESEND_API_KEY` الاستمارة تشتغل وتطبع الطلب في سجل الخادم فقط (يكفي للمسودة).

## 6. ⚠️ لازم نجيبه من مجد (بالأولوية)

1. **ملاحظاته على المسودة**: الشكل، الصور المختارة، ترتيب الأقسام، النصوص.
2. **تأكيد بيانات كل دورة**: الساعات واللقاءات (منقولة من الموقع القديم)، ونص الشهادة لكل دورة (خصوصاً: التكييف م2 "رخصة كهربائي خدمة درجة ב'"، ومساعد أمان).
3. **دورات ظاهرة على فيسبوك وغير موجودة بالموقع** — هل نضيفها؟ مشغّل رافعة شاحنة + مشير (מפעיל מנוף משאית + אתת)، قراءة الخرائط الهندسية، تقييم أضرار الممتلكات (שמאות רכוש)، محاسب أجور (חשב שכר)، PLC.
4. **ساعات الدوام** (ناقصة في الموقع وفي صفحة خرائط جوجل).
5. **لوغو بجودة عالية** (الحالي 250 بكسل، يظهر باهتاً على الشاشات الحديثة).
6. **موافقة الطلاب** على نشر صورهم (الخريجون + صور الورشات).
7. **الخبر الأحدث** "توزيع الشهادات — أيلول 2026": الصور من فيسبوك بدون نص، العنوان عام — يؤكد أو يعدّل.
8. **رابط إنستغرام** إن وُجد، وروابط مواقع الشركاء.
9. **صفحة الفيسبوك تستخدم عبارات "الشغل مضمون" و"التعليم مجاني"** — مخالفة لقاعدة المشروع. الموقع نظيف، لكن يُفضّل توحيد الصياغة على فيسبوك أيضاً.

> الدومين: القرار متّخذ (الاحتفاظ بـ `almrkz.net`، الرسالة قبل الإطلاق بأسبوع). **لا تكرّر التحذير** — التفاصيل في `docs/CONSULTATION-2026-09-11.md` قسم 5.

## 7. الخطوات القادمة (بالترتيب)

1. عرض المسودة على مجد → تعديلات.
2. رفع الموقع على Vercel برابط مؤقت (مثل `almrkz.vercel.app`) ليشوفوه من الموبايل.
3. تعبئة المفاتيح (القسم 5) + اختبار الاستمارة بالإيميل.
4. أداة وصولية معتمدة (تعليق الشرح في `src/components/AccessibilityWidget.tsx`).
5. فتح صفحة خرائط جوجل — مهمة حسين/مجد (الخطوات في `docs/CONSULTATION-2026-09-11.md` قسم 8).
6. الدومين: رسالة للمبرمجة السابقة قبل الإطلاق بأسبوع (الرسالة جاهزة في تقرير الاستشارة).
7. الإطلاق على `almrkz.net`، ثم Google Search Console.
8. المرحلة 2: Payload CMS + ربط استمارات فيسبوك بقائمة موحّدة.

## 8. قرارات تقنية اتخذت (للمرجع)

- Next.js 16 + TypeScript + Tailwind v4. الخطوط: Almarai (عربي) و Heebo (عبري) من Google Fonts.
- الروابط بالإنجليزي (`/courses/welding/welding-pipes`) لتكون نفسها باللغتين، وتبديل اللغة يبدّل البادئة فقط.
- الفيديوهات تُعرض من يوتيوب مباشرة؛ ملفات mp4 الأصلية غير مرفوعة على git (`.gitignore`).
- الصور الأصلية في `assets/`، والموقع يستخدم نسخاً مضغوطة في `public/images/` تُولَّد بـ `npm run images`.
- الصفحة الجذر `/` تحوّل تلقائياً إلى `/ar`.
- الاستمارة تعمل بـ Server Action (بدون API خارجي)، مع مصيدة روبوتات وتحقق من رقم الهاتف.
