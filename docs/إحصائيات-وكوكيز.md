# إحصائيات الموقع ورسالة الكوكيز — دليل لحسين ومجد

**الفكرة باختصار:** الموقع جاهز لـ Google Analytics (كم زائر، أي صفحات) و Meta Pixel (قياس إعلانات فيسبوك/إنستغرام).
هلّأ هم **مطفيين**: ما في رسالة كوكيز، وما في ولا أداة بتشتغل. بيشتغلوا بس لما تحطّوا الأرقام (IDs) في Vercel.

## 1. مجد بيعمل الحسابات (بحساب الكلية، مش حساب شخصي)
| الأداة | وين | شو بتاخدوا منها |
|---|---|---|
| Google Analytics | analytics.google.com ← «إنشاء حساب» ← Property باسم الكلية (منطقة زمنية: إسرائيل) ← Data stream من نوع **Web** بعنوان الموقع | **Measurement ID** — شكله `G-XXXXXXXXXX` |
| Meta Pixel | business.facebook.com ← Events Manager ← «ربط مصادر بيانات» ← **Web** ← اسم: موقع الكلية | **Pixel ID** (أو Dataset ID) — أرقام بس |
| Google Search Console (اختياري) | search.google.com/search-console ← طريقة التحقق **HTML tag** | بس القيمة اللي جوّا `content="..."` |

## 2. وين نحط الأرقام
Vercel ← المشروع ← **Settings ← Environment Variables** ← أضيفوا (Production):

| الاسم | القيمة |
|---|---|
| `NEXT_PUBLIC_GA_ID` | رقم Google مثل `G-AB12CD34EF` |
| `NEXT_PUBLIC_META_PIXEL_ID` | رقم الـ Pixel |
| `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` | (اختياري) قيمة Search Console |

بعدين: **Deployments ← آخر نشر ← ⋯ ← Redeploy**. بدون Redeploy ما بيتغيّر إشي. ممكن تحطّوا وحدة بس (Google لحالها مثلاً).
لإطفاء كل إشي: امسحوا الأرقام واعملوا Redeploy.

## 3. شو بيصير بالموقع بعد ما نحط الأرقام
- أول ما حدا يفوت، بتطلع رسالة صغيرة تحت: «موافق» / «رفض» + رابط «التفاصيل» لسياسة الخصوصية.
- **قبل ما يختار، أو إذا رفض — ولا أداة بتشتغل ولا كوكيز.** هيك بيطلب قانون الخصوصية (تعديل 13).
- الاختيار بينحفظ 6 شهور. بأسفل كل صفحة في رابط «إعدادات الكوكيز» لتغيير الاختيار.
- صفحة سياسة الخصوصية بتتغيّر لحالها وبتشرح إنّا بنستعمل هاي الأدوات.
- الموقع بيسجّل: زيارات الصفحات، إرسال استمارة «سجّل اهتمامك» (مع اسم الدورة بس) = `generate_lead` بـ Google و `Lead` بـ Meta، وضغطات واتساب/اتصال = `contact`.
- **ما بنبعت أسماء ولا أرقام تلفونات** لـ Google أو Meta.

## 4. كيف نتأكد إنه شغّال
1. افتحوا الموقع بمتصفح عادي ← اضغطوا «موافق».
2. Google Analytics ← **Reports ← Realtime**: لازم تشوفوا حالكم خلال دقيقة.
3. Meta Events Manager ← الـ Pixel ← **Test events** ← حطّوا عنوان الموقع ← لازم يطلع `PageView`.
4. عبّوا الاستمارة (تجربة) ← بيطلع `generate_lead` بـ Google (بعد شوي) و `Lead` بـ Meta. امسحوا طلب التجربة من اللوحة.
5. بـ Google Analytics ← Admin ← Events: علّموا `generate_lead` كـ **Key event** (تحويل) عشان يبيّن بالتقارير.

ملاحظة: إذا اضغطتوا «رفض» على جهازكم، ما رح تشوفوا حالكم — هاد صح. غيّروا الاختيار من «إعدادات الكوكيز».
