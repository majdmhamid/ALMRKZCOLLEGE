## 2. القرارات المتّفق عليها

| البند | القرار |
|---|---|
| اللغات | **عربي** (أساسي) + **عبري** |
| عدد الدورات | 10–20 |
| تنظيم الدورات | **مجموعات** ← وتحتها دورات فرعية |
| التواصل | زر واتساب مباشر **+** استمارة "سجّل اهتمامك" — الاثنان معاً |
| الأسعار | **لا تُعرض على الموقع.** الطالب يتواصل والكلية تعطيه السعر |
| الشوفاريم (שוברים) | يُذكر أن الدورة *"ملائمة للحصول على منحة — تواصل معنا للاستشارة"* |
| الستايل | جدّي ومحترم **+** عصري وحيوي معاً |
| القرار النهائي | حسين **أو** ماجد |
| الإطلاق | بأسرع وقت، على مراحل حسب الأولويات |

### ⚠️ قاعدة الصياغة حول التشغيل — إلزامية

الكلية **لا تلتزم** بتأمين عمل للخريج. ممنوع أي صياغة توحي بالضمان.

| ❌ ممنوع | ✅ مسموح |
|---|---|
| "ضمان تشغيل" / "הבטחת תעסוקה" | "مرافقة وتوجيه مهني بعد التخرّج" |
| "بنشغّلك بعد الدورة" | "توجيه: شو السوق، أي الشركات، وين الفرص" |
| "شغل مضمون" | "علاقات مع شركات ومقاولين في المنطقة" |

يُضاف تنويه واضح في كل مكان يُذكر فيه التشغيل:
> *«الكلية تقدّم مرافقة وتوجيه مهني، ولا تلتزم بتأمين مكان عمل.»*

## 3. خريطة الموقع

```
الرئيسية
├── الدورات
│   ├── مجموعة: الحديد ────────► لحام (ריתוך) م1 · لحام م2 · حدادة بناء
│   ├── مجموعة: السلامة ───────► עוזר בטיחות · מנהל עבודה
│   ├── مجموعة: التكييف ───────► فني تكييف م1 · فني تكييف م2
│   └── ... (باقي المجموعات)
├── عن الكلية        (التأسيس 2008 · اعتماد وزارة العمل · الورشات والمعدات)
├── معرض الصور والفيديو
├── قصص نجاح الخريجين
├── أخبار وإعلانات
├── للشركات والمشغّلين   (تأهيل موظفين · دورات داخلية)
└── اتصل بنا         (عنوان · هواتف · خريطة · استمارة · واتساب)
```

كل صفحة موجودة بنسختين: `/ar/...` و `/he/...`

## 5. المراحل

### المرحلة 1 — الإطلاق (الأولوية القصوى)
- كل الصفحات أعلاه، عربي + عبري، RTL كامل
- كل الدورات مع مجموعاتها
- زر واتساب + استمارة "سجّل اهتمامك" (تصل بالإيميل + تُحفظ بقائمة)
- سرعة عالية + ملائم للموبايل + ظهور جيد بجوجل (SEO)
- **المحتوى في هذه المرحلة يُحدَّث عبر المطوّر**

### المرحلة 2 — لوحة التحكم
- لوحة تحكم **بالعربي واتجاه RTL**
- إضافة/تعديل/حذف دورة ومجموعة
- رفع وتبديل الصور والفيديو
- نشر خبر أو قصة نجاح
- إدارة طلبات التسجيل الواردة

### المرحلة 3 — منظومة التسجيل
- ملف تسجيل رسمي، رفع مستندات، متابعة حالة الطلب
- (تُناقَش تفاصيلها لاحقاً)

## 6. الاختيار التقني — وشو معناه بلغة بسيطة

**التوصية: Next.js + Payload CMS**

| الاسم | شو يعني إلكم |
|---|---|
| **Next.js** | محرّك الموقع — بيخلّيه **سريع جداً** وبيظهر منيح بجوجل |
| **Payload CMS** | لوحة التحكم — **بتدعم العربي واتجاه RTL**، وهاي السبب الأساسي لاختيارها |
| **Tailwind CSS** | أداة تصميم — بتخلّي الشكل متناسق وسريع التعديل |
| **Vercel** | الاستضافة — سريعة وموثوقة وبتتجدد تلقائياً |

### ليش مش UI بس بدون back-end؟
لأن طلبكم واضح: *«الموقع يكون سهل التعديل عليه — نزيد فيديو، نغيّر صورة، نزيد كورس»*.
هذا **يستحيل** بدون back-end. أي موقع "UI فقط" بيلزمه مبرمج لكل تغيير — وهذا عكس المطلوب.

### الحل الوسط المعتمد
نبني المرحلة 1 بسرعة، لكن **على نفس الأساس التقني** الذي ستُركّب عليه لوحة التحكم في المرحلة 2.
النتيجة: إطلاق سريع، **بدون** هدم وإعادة بناء لاحقاً.
