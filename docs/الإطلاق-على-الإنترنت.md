# الإطلاق على الإنترنت — خطوة بخطوة

<div dir="rtl">

بدنا حسابين بس: **Supabase** (قاعدة البيانات، الصور، ملفات التوقيع) و**Vercel** (تشغيل الموقع).
بتقدروا تبلّشوا على حساب حسين، وبعدين تنقلوها لمجد:
- **Supabase:** كل إشي جوّا «منظمة» خاصة بالكلية ← بتضيفوا مجد مالك (Owner) وبتطلع إنت. مجاني، وبدون توقّف.
- **Vercel:** مجد بيعمل مشروع جديد بحسابه وبينسخ نفس المفاتيح (ربع ساعة). للإطلاق الرسمي الأفضل خطة Pro (استعمال تجاري).

> ⚠️ الدومين `almrkz.net` ما منلمسه هلأ — منجرّب أول على رابط Vercel المؤقت.

---

## ١. Supabase (10 دقايق)

1. **supabase.com** ← اسم حسابك فوق ← **New organization** ← الاسم `Almrkz College` ← خطة **Free**.
2. جوّا المنظمة: **New project** ← الاسم `almrkz` ← **Generate password** (احفظها!) ← المنطقة **Central EU (Frankfurt)**.
3. **Authentication** ← **Sign In / Providers** ← طفّي **Allow new users to sign up** ← **Save**.
4. **Storage** ← **New bucket** ← الاسم `media` ← علّم **Public bucket** ← **Save** (صور الموقع).
5. **Storage** ← **Settings** ← **S3 Connection** ← **New access key** ← احفظ الـ Access key والـ Secret.

## ٢. المفاتيح (مع كلود)

احكي لكلود: *«خلص Supabase، ساعدني بالمفاتيح»*. كلود بيحكيلك وين تنسخ كل واحد لملف `.env` على جهازك —
**لا تبعت المفاتيح بالمحادثة**. بعدها كلود بيشغّل:
```bash
npm run secrets
npm run db:migrate
npm run migrate
npm run seed
```
(جداول التوقيع، جداول الموقع، وتعبئة المحتوى من التصميم + أول حساب مدير.)

## ٣. Vercel (10 دقايق)

1. **vercel.com** ← **Add New** ← **Project** ← اختار المستودع ← الفرع اللي كلود بيحكيلك عليه.
2. **Environment Variables** ← كل سطر من `.env` (ما عدا `MOCK_BACKEND`). `NEXT_PUBLIC_SERVER_URL` و`NEXT_PUBLIC_APP_URL` = عنوان Vercel.
3. **Deploy** ← بياخد 5–8 دقايق ← افتح `https://<اسم-المشروع>.vercel.app/ar` و`/admin`.

## ٤. تجربة سريعة بعد الإطلاق
- ادخل على `/admin` ← الخريجون ← غيّر اسم ← «انشر» ← افتح الموقع.
- المستندات ← ارفع PDF صغير ← ابعت رابط لرقمك ← وقّع من جوالك.
