# الإطلاق على الإنترنت — خطوة بخطوة

<div dir="rtl">

بدنا حسابين بس: **Supabase** (قاعدة البيانات، الصور، ملفات التوقيع) و**Vercel** (تشغيل الموقع).
بتقدروا تبلّشوا على حساب حسين، وبعدين تنقلوها لمجد (التفاصيل بالبند ٨):
- **Supabase:** كل إشي جوّا «منظمة» خاصة بالكلية ← بتضيفوا مجد مالك (Owner) وبتطلع إنت. مجاني، وبدون توقّف.
- **Vercel:** مجد بيعمل مشروع جديد بحسابه وبينسخ نفس المفاتيح (ربع ساعة). للإطلاق الرسمي لازم خطة Pro (استعمال تجاري).

> ⚠️ الدومين `almrkz.net` ما منلمسه هلأ — منجرّب أول على رابط Vercel المؤقت.

---

## ١. Supabase (10 دقايق)

1. **supabase.com** ← اسم حسابك فوق ← **New organization** ← الاسم `Almrkz College` ← خطة **Free**.
2. جوّا المنظمة: **New project** ← الاسم `almrkz` ← **Generate password** (احفظها بمدير كلمات السر — البند ٧) ← المنطقة **Central EU (Frankfurt)**.
3. **Authentication** ← **Sign In / Providers** ← طفّي **Allow new users to sign up** ← **Save**.
4. **Storage** ← **New bucket** ← الاسم `media` ← علّم **Public bucket** ← **Save** (صور الموقع).
5. **Storage** ← **Settings** ← **S3 Connection** ← **New access key** ← احفظ الـ Access key والـ Secret.

## ٢. المفاتيح وأول حساب مدير (مع كلود)

احكي لكلود: *«خلص Supabase، ساعدني بالمفاتيح»*.
1. كلود بيشغّل `npm run secrets` ← بينعمل ملف `.env.local` على جهازك، وفيه **4 مفاتيح سرية** جاهزة:
   `PAYLOAD_SECRET` (دخول لوحة التحكم) + 3 مفاتيح التوقيع. إذا المفتاح موجود، ما بيغيّره أبداً.
2. كلود بيحكيلك وين تنسخ كل مفتاح من Supabase لملف `.env.local` — **لا تبعت المفاتيح بالمحادثة**.
3. **حساب المدير الأول** — إنت بتكتبه بنفس الملف بإيدك (مش بالمحادثة):

| السطر | شو بتكتب |
|---|---|
| `SEED_ADMIN_EMAIL` | إيميل المدير (مثلاً إيميل الكلية) |
| `SEED_ADMIN_PASSWORD` | كلمة سر قوية — واحفظها بمدير كلمات السر |

4. بعدها كلود بيشغّل:
```bash
npm run db:migrate
npm run migrate
npm run seed
```
(جداول التوقيع، جداول الموقع، وتعبئة المحتوى من التصميم + **أول حساب مدير**.)

> ⚠️ **حساب المدير لازم يكون موجود قبل ما تبعتوا رابط Vercel لأي حدا.**
> إذا ما في مدير، أول واحد بيفتح `/admin` بيصير هو المدير.

## ٣. إيميل الطلبات (Gmail — هلأ)

مع كل طلب «سجّل اهتمامك» بيوصل إيميل. هلأ منبعت من Gmail الكلية `almerkaz.collega@gmail.com`:

**مجد (5 دقايق):**
1. ادخل على **myaccount.google.com** بحساب الكلية ← **Security** ← تأكد إنه **2-Step Verification** شغّال (إذا لأ، شغّله).
2. افتح **myaccount.google.com/apppasswords** ← الاسم `almrkz-site` ← **Create**.
3. بتطلع **كلمة سر تطبيق** (16 حرف). حطّها بمدير كلمات السر (البند ٧) — **مش بالواتساب ولا بأي محادثة**.

**حسين:** بيلصق هاي القيم مباشرة بـ Vercel ← **Environment Variables** (البند ٤):

| المفتاح | القيمة |
|---|---|
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `587` |
| `SMTP_USER` | `almerkaz.collega@gmail.com` |
| `SMTP_PASS` | كلمة سر التطبيق (بدون فراغات) |
| `EMAIL_FROM_ADDRESS` | `almerkaz.collega@gmail.com` |

مين بيستلم الطلبات؟ من لوحة التحكم ← **إعدادات الموقع** ← **إشعارات الطلبات**.

**بعدين — لما يصير الدومين `almrkz.net` إلنا:** منحوّل لـ **Resend** (الإيميلات بتوصل أحسن وبتطلع من `no-reply@almrkz.net`). بدون أي تغيير بالكود:
1. **resend.com** ← حساب بإيميل الكلية ← **Domains** ← **Add** ← `almrkz.net`.
2. بيعطيك كم سطر **DNS** ← بينحطّوا عند شركة الدومين ← **Verify**.
3. **API Keys** ← **Create** ← احفظه بمدير كلمات السر.
4. بـ Vercel بتغيّر: `SMTP_HOST` = `smtp.resend.com` · `SMTP_USER` = `resend` · `SMTP_PASS` = الـ API key ·
   `EMAIL_FROM_ADDRESS` = `no-reply@almrkz.net` · (`SMTP_PORT` بيضل `587`) ← **Redeploy**.

## ٤. Vercel (10 دقايق)

1. **vercel.com** ← **Add New** ← **Project** ← اختار المستودع ← الفرع الرئيسي `claude/clever-heisenberg-waag9g`.
2. **Environment Variables** ← كل سطر من `.env.local` (ما عدا `MOCK_BACKEND`) + قيم الإيميل من البند ٣.
   `NEXT_PUBLIC_SERVER_URL` و`NEXT_PUBLIC_APP_URL` = عنوان Vercel.
3. **Deploy** ← بياخد 5–8 دقايق ← افتح `https://<اسم-المشروع>.vercel.app/ar`.

> كل ما تغيّر قيمة بـ Environment Variables: **Deployments** ← آخر واحد ← **Redeploy**، عشان التغيير يمشي.

## ٥. فحص المدير — قبل ما تبعتوا الرابط لحدا

افتح `https://<اسم-المشروع>.vercel.app/admin`:

| شو طلع | يعني |
|---|---|
| صفحة **دخول** (إيميل + كلمة سر) | ✅ تمام — ادخل بحساب المدير من البند ٢ |
| صفحة **Create first user** (عمل أول مستخدم) | ❌ ما في مدير. **لا تعبّيها ولا تبعت الرابط لحدا** — احكي لكلود |

## ٦. تجربة سريعة بعد الإطلاق
- ادخل على `/admin` ← الخريجون ← غيّر اسم ← «انشر» ← افتح الموقع.
- المستندات ← ارفع PDF صغير ← ابعت رابط لرقمك ← وقّع من جوالك.
- عبّي «سجّل اهتمامك» بالموقع ← لازم يوصل إيميل.

## ٧. احفظوا الأسرار بمدير كلمات سر

استعملوا **مدير كلمات سر** (مثل Bitwarden أو 1Password أو مدير كلمات السر تبع Google) — مش ورقة ولا واتساب.

| شو | من وين |
|---|---|
| كلمة سر قاعدة البيانات | Supabase — البند ١ |
| S3 Access key + Secret | Supabase — البند ١ |
| `PAYLOAD_SECRET`، `ID_HMAC_SECRET`، `TOKEN_ENC_KEY`، `SESSION_SECRET` | ملف `.env.local` بعد `npm run secrets` |
| كلمة سر المدير الأول | البند ٢ |
| كلمة سر تطبيق Gmail (وبعدين مفتاح Resend) | البند ٣ |

> ⚠️ **مفاتيح التوقيع الثلاثة** (`ID_HMAC_SECRET`، `TOKEN_ENC_KEY`، `SESSION_SECRET`) **ممنوع تتغيّر أبداً**
> بعد ما تبلّشوا تستعملوا التوقيع — وإلا روابط ومستندات التوقيع القديمة بتخرب.
> و`PAYLOAD_SECRET` كمان خلّوه نفسه (إذا تغيّر، الكل بيطلع من لوحة التحكم).
> إذا غيّرتوا كلمة سر قاعدة البيانات: بس حدّثوا `DATABASE_URL` و`SUPABASE_DB_URL` بـ Vercel.

## ٨. التسليم لمجد

| شو | الخطوات |
|---|---|
| **Supabase** | المنظمة `Almrkz College` ← **Team** ← **Invite** ← إيميل مجد ← الدور **Owner**. مجد بيقبل الدعوة ← بعدها حسين بيطلع (**Leave organization**) |
| **Vercel** | مجد بيفتح حساب/فريق خاص فيه ← خطة **Pro** (خطة Hobby المجانية مسموحة بس لاستعمال شخصي، مش تجاري) ← **Add New** ← **Project** ← نفس المستودع ← بينسخ كل الـ Environment Variables من مشروع حسين ← **Deploy** ← فحص البند ٥ |
| **الدومين `almrkz.net`** | القرار: منبعت للمبرمج السابق قبل الإطلاق بأسبوع |

## ٩. بعد الإطلاق على الدومين الحقيقي
1. بـ Vercel حدّث `NEXT_PUBLIC_SERVER_URL` و`NEXT_PUBLIC_APP_URL` = العنوان الجديد (مثلاً `https://www.almrkz.net`) ← **Redeploy**.
2. **Google Search Console** (search.google.com/search-console) ← **Add property** ← **Domain** ← `almrkz.net` ←
   بيعطيك سطر DNS للتأكيد ← **Verify** ← **Sitemaps** ← اكتب `sitemap.xml` ← **Submit**.
3. الإيميل: حوّلوا لـ Resend (البند ٣).
4. إحصائيات الزوار (Analytics): بعدين، مش هلأ.
