## ملاحظات

- الملفات محفوظة على GitHub عبر **Git LFS** (نظام للملفات الكبيرة)، لأن GitHub ما بيقبل
  ملف أكبر من 100 ميغا بالطريقة العادية.
- هاي **نسخ أصلية** للأرشيف. قبل عرض أي فيديو على الموقع لازم نصغّره ونحوّله
  لصيغة مناسبة للويب (زي `public/videos/hero.mp4` اللي حجمه أقل من 1 ميغا).
- إذا فتحت المشروع على كمبيوتر تاني ولقيت الملفات صغيرة جداً (كام سطر نص)،
  معناها Git LFS مش مثبّت. الحل: `git lfs install` وبعدين `git lfs pull`.
