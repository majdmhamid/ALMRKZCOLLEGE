# موقع كلية المركز للتأهيل المهني — أم الفحم

مستودع تطوير الموقع الجديد لكلية المركز للتأهيل المهني (تأسست 2008، بإشراف وزارة العمل).
الموقع الحالي: `almrkz.net` — والهدف بناء نسخة جديدة أحدث وأفضل بكثير.

## 👥 أصحاب القرار
- **حسين** — إدارة المشروع
- **ماجد** — صاحب الكلية

موافقة أي واحد منهما ملزِمة.

## ⚠️ الوضع الحالي
**الصفحة الرئيسية مبنية** حسب تصميم *Option F — نسخة صاحب الكلية* (من Claude Design).
العبري هو اللغة الأساسية (`/he`)، والعربي على `/ar` — زر التبديل فوق.

لسا مش جاهز للإطلاق:
- **استمارة "رجعولي"** بتستقبل الطلب بس لسا ما بتبعته إيميل — بدنا نقرر لأي إيميل يوصل.
- **مواعيد الأفواج تجريبية** — بتتعدّل بملف `content/courses.ts` (`startDates`)، وفي مفتاح `showStartDates` بيخفيهن كلهن.
- **صور الريلز الأربعة** لسا صور دورات مؤقتة — لما توصل الصور/الفيديوهات الحقيقية بتنحط بنفس المكان.
- حسم ملكية الدومين (تفاصيل في `docs/OPEN-ITEMS.md`).

## 🛠️ للمطوّر

Next.js (App Router) + TypeScript. كل النصوص والبيانات بمجلد `content/` — ما في نصوص مكتوبة جوّا المكوّنات.

```bash
npm install
npm run dev     # http://localhost:3000 → /he
npm run build && npm start
```

| المسار | شو فيه |
|---|---|
| `app/[locale]/page.tsx` | الصفحة الرئيسية (كل الأقسام) |
| `app/globals.css` | كل الستايل — ألوان الكلية بمتغيرات `:root` |
| `components/` | الأجزاء التفاعلية: القائمة، فلتر الدورات، الأسئلة، الفيديو، الاستمارة |
| `content/` | الدورات، المواعيد، الخريجين، الطاقم، الأخبار، والنصوص بالعبري والعربي |
| `app/api/lead/route.ts` | استقبال الاستمارة — هون بينربط الإيميل |
| `public/assets/` | الصور والفيديو واللوغو |
