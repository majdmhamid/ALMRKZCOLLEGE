# موقع كلية المركز للتأهيل المهني — أم الفحم

الموقع الجديد لكلية المركز للتأهيل المهني (تأسست 2008، بإشراف وزارة العمل).
الموقع الحالي: `almrkz.net` — والنسخة الجديدة جاهزة للتجربة وبانتظار الإطلاق.

## 👥 أصحاب القرار
- **حسين** — إدارة المشروع
- **مجد** — صاحب الكلية

موافقة أي واحد منهما ملزِمة.

## ✅ شو موجود
| الجزء | وين |
|---|---|
| الموقع العام بالعربي والعبري (التصميم A) | `/ar`، `/he` |
| لوحة التحكم بشكل الموقع — التعديل على نفس البطاقات | `/admin` |
| التوقيع الإلكتروني جوّا نفس اللوحة + صفحة التوقيع للعميل | `/admin/documents`، `/sign/...` |

التقنيات: Next.js 16 + Payload CMS 3 + TypeScript · قاعدة البيانات والتخزين: Supabase · الاستضافة: Vercel.
الفرع الرئيسي: **`claude/clever-heisenberg-waag9g`** — كل مهمة جديدة بفرع منه.

## 💻 تشغيل الموقع على جهازك

**لحسين ومجد (بدون برمجة):** دبل كليك على `start-windows.bat` (أو `start-mac.command` على ماك) —
الشرح الكامل في [`شغّل-الموقع-على-جهازك.md`](شغّل-الموقع-على-جهازك.md).

**للمبرمج (Claude):**
```bash
npm install
npm run dev        # الموقع: http://localhost:3000/ar  ·  لوحة التحكم: /admin
```
بدون `DATABASE_URL` كل إشي بينحفظ بملف محلي (`almrkz-local.db`)، والتوقيع بيشتغل بوضع تجربة.
للاتصال بـ Supabase: `npm run secrets` (بيعمل `.env.local` من `.env.example` مع المفاتيح السرية)، وبعدين عبّي قيم Supabase فيه — التفاصيل في دليل الإطلاق.

فحوصات: `npm test` · `npm run lint` · `npm run typecheck` · `npm run build`
