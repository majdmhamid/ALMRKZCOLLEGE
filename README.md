# موقع كلية المركز للتأهيل المهني — أم الفحم

الموقع الجديد لكلية المركز للتأهيل المهني (تأسست 2008، بإشراف وزارة العمل).
الموقع الحالي: `almrkz.net` — وهذا المستودع فيه النسخة الجديدة بالعربي والعبري.

## 👥 أصحاب القرار
- **حسين** — إدارة المشروع
- **مجد** — صاحب الكلية

موافقة أي واحد منهما ملزِمة.

## ▶️ تشغيل الموقع على الكمبيوتر

```bash
npm install
npm run dev
```
ثم افتح `http://localhost:3000/ar` (عربي) أو `http://localhost:3000/he` (عبري).
